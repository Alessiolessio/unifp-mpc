Evidence inventory and reproduction guide

Use this guide with the research report, recordings and frozen protocol. Each row identifies a source collection and its unit of observation. An archive row can describe an action branch, a controller run, a summary or a repeated physical condition. Adding the row counts across these collections would inflate the sample size.

Statistical and figure files

  • Source table inventory gives every original CSV in docs/, its row count, column count and digest. It indexes derived tables as well as trial data. Proposed evaluation documents the pre-freeze planning stage. Frozen manifest gives actual assignments.
  • Group outcomes, metric distributions, terminal statuses and paired endpoint distributions retain physical units and all valid endpoints. Frozen paired success and shared completion times and runtime paired uncertainty use physical scenes as clusters.
  • Fixed-goal distributions, within-placement pairs and policy and secondary summaries and paired fixed-command effects preserve treatment, task and sample counts. Use the source study's per-tick/substep definitions for physical measurements. Blank cells denote inapplicable or unavailable measurements.
  • Pooled timing distributions distinguish end-to-end planning from the complete synchronous cycle wherever tick-level cycle samples were retained. Deadline counts use actual wall-clock measurements.
  • Figures in SVG, PDF and PNG use the same filename stem across formats. Captions in the report link to the source rows or trajectories. Report recordings include selected pose replays and animated measurements. Media manifest covers both new and linked archive recordings. Existing synchronized forecasts and the precise timing convention are documented in the telemetry guide.

Reading the tables

Field or convention Meaning
block,task,physics,arm Frozen UniFP general and challenge, frozen ReLIC sumo, or separate supplement_runtime. known is a matched plant. blind and informed share the heavy execution plant. runtime is the four-run frozen subset. runtime_full is the supplemental suite.
scene_seed,cem_seed Physical placement and optimizer draw. In fixed commands case identifies the physical condition. An A trajectory can be reused for comparisons to both signs.
final_error Metres of XY error for box/tether, degrees of tilt for cone. The fixed-goal final_error distributions are in metres; the explicit B-minus-comparator endpoint columns are in mm.
settled_s,upright_s,sim_s Time to confirmed hold, first native axis crossing, and observation duration. A blank completion time is censored by termination. n in completion summaries can be smaller than the assigned episode count.
safe_strict, end_settled Whole-episode clean success for box/cone; separately, a qualifying fixed-command hold in the last half-second. A transient threshold crossing cannot establish either.
tipping_Nms, axial_m, hand_impulse_Ns Signed hand moment integrated about the observed support region, impulse-weighted axial location along the cone, and integral of the hand-force resultant. Substep and policy-tick peak definitions differ; see the source column names.
mean_absolute, rms, sd Computed over nonmissing episode metrics. For signed errors, mean absolute value gives MAE. An RMS across episode-level RMS values is a different summary from pooling every physics tick. SD uses the sample denominator; a singleton has no sample SD. Timing tables separately pool actual replans in ms.
Paired effects Left minus right in source units. Positive success delta favors the left arm, negative error delta favors the left arm. A numerically higher impulse or displacement is not itself a task win. Limits are descriptive scene/placement bootstrap percentiles.

Reproduction from the archived workspace

Run commands from the repository root. The simulation artifacts, checkpoint, native build and sibling checkouts must be available to reproduce or rescore the entire archive. A source-only clone does not contain the ignored experiment tree. The illustrated HTML embeds vector figures for offline reading; CSV and MP4 links use the adjacent repository and archive layout.

First verify the supplemental evidence before regenerating any scientific outputs. Rendering below writes exclusively to report directories or temporary files. The original experimental runners in the historical guides may write beside their archives; use a separate workspace when reproducing a simulation.

sha256sum --quiet -c artifacts/supplemental/evidence.sha256
python tools/report_statistics.py
python tools/report_figures.py
python tools/report_html.py

The report build used Python 3.11.15, NumPy 1.26.0, Matplotlib 3.10.3, Python-Markdown 3.10.3 and FFmpeg 7.0.2. This analysis environment is separate from the locked simulator environment. The statistics script imports the checked-in physical scorer. Source data and rendering are local; the generated pages need no external scripts or fonts. For optional media reproduction, use the calibrated native environment for UniFP and SUMO's pinned environment for ReLIC. Provide the absolute path to an FFmpeg executable with H.264 and subtitle support. For example, on the report host:

export PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tests:tools:build
export OPENBLAS_NUM_THREADS=1 MUJOCO_GL=osmesa
ffmpeg_bin=$(python -c 'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())')
for family in pulse box slide raw wall mismatch; do
  .pixi/envs/default/bin/python tools/report_recordings.py "$family" --ffmpeg "$ffmpeg_bin"
done
for family in relic relic_cone; do
  ../sumo/.pixi/envs/default/bin/python tools/report_recordings.py "$family" --ffmpeg "$ffmpeg_bin"
done
python tools/report_figures.py --movies --ffmpeg "$ffmpeg_bin"
python tools/report_html.py --verify-media --ffmpeg "$ffmpeg_bin"

pulse replays just case 4201 with its undisturbed twins and checks A/B/C against the original CSV. Other camera commands reconstruct archived poses; mj_forward is used for camera kinematics only. The figures and aggregate physical force measurements use the archived integrated samples. The original frozen experiments, optional policy diagnostics and serial timing commands are documented in the methods, protocol, fixed-policy guide and supplemental handoff. Running the full benchmark is unnecessary for this report.

The study supports conclusions about the specified simulated plants and checkpoints. Optimizer seeds on one scene share its mechanics, masses paired at the same placements share geometry, and ticks in a contact share a physical history. Development-guided changes, replayed command branches and selected videos each answer different questions from a fresh physical-scene evaluation. The statistical tables and figure captions preserve those distinctions.
